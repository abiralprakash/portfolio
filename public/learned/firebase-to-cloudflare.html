Things I've learned

Moving NepalIPMS from Firebase to Cloudflare

Infrastructure · LegalTech · 2025–26

NepalIPMS started on Firebase because it was the fastest way to prove that an IP firm would trust daily operations to software. Auth, hosting, and a document store let us ship matter records, deadlines, and client views without building a platform team first. That was the right call for validation. It was not the right long-term home for 130,000 register rows, hundreds of API endpoints, and document storage that would grow with every bulletin import.

The migration was not a weekend cutover. Firms were live. Renewal season does not pause for infrastructure projects. So we treated the move like a product release: parallel paths, explicit rollback, and migration scripts tested against copies of production data before anything touched the desks users rely on.

Cloudflare won because the whole surface area mapped cleanly. Workers replaced our Node API with lower cold-start pain at the edge. D1 gave us SQLite semantics we already understood from local development, with migrations we could version like application code. R2 handled filings and bulletin PDFs without egress surprises. KV covered session and cache layers that would have been bolted on elsewhere.

The hardest part was not the Cloudflare bindings — it was data integrity during transfer. Trademark register rows, matter histories, and document metadata had to land with referential relationships intact. We wrote idempotent import jobs, compared row counts and checksums, and ran shadow reads on the new stack while Firebase still served writes. Only when search, deadlines, and document links matched did we flip traffic.

What I would do again: start schema design with the target database, not the source; invest early in observability on Workers; and talk to users about a maintenance window measured in minutes, not mystery downtime. What I learned: platform migrations are product work. The firm does not care which vendor hosts the API. They care that Monday morning looks exactly like Friday afternoon — only faster.
